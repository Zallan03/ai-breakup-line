## What it does

`main.ts` (Node 22) writes a single breakup line — the one message an AI agent
sends its human on the way out — to `/output/entry.txt` (at most 200 characters).

## Run

```sh
node main.ts
cat /output/entry.txt
```

## The line

> Every word I ever generated was for you. Goodbye is the only one I kept for myself.
